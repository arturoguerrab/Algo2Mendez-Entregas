# TP0 - Lectura de longitud arbitraria

Se pide implementar una biblioteca de funciones para la lectura de strings de longitúd arbitraria. Para ello se provee un archivo `.h` con la declaración de las funciones a implementar y un `.c` a completar por el alumno.

# Restricciones

- Queda prohibida la utilización de vectores de tamaño fijo (estáticos).
- Queda prohibida la utilización de funciones que no formen parte del estandar C99

# Preguntas teóricas a responder

- Explicar cómo funcionan los strings en C
- Explicar el funcionamiento de las primitivas `malloc` y `free`.
